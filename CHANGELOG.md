# Изменения

Каждая версия начинается со строки `## <версия> — <дата>`. Уведомление об обновлении в Redmine показывает
пункты всех версий новее установленной. Если версия меняет базу данных, в пункте есть слово «миграция».

## 1.1.0 — 2026-11-25

- Проверка обновлений: раз в сутки модуль сверяет свою версию с GitHub и показывает администраторам
  уведомление на страницах «Администрирование» и «Модули» со списком изменений и инструкцией по обновлению.
- Проверка из консоли: `rake redmine:search_control:check_update`.
- Автор и ссылки на GitHub в списке модулей.

## 1.0.0 — 2026-11-24

- Первая версия: фильтр «Имя, email или логин» всегда на странице пользователей, пустое значение не фильтрует.
